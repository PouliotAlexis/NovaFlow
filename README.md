# NovaFlow 🚀

**NovaFlow** est votre système d'exploitation de vie ("Life OS") unifié, conçu pour centraliser intelligemment vos informations académiques, professionnelles et personnelles.

> "Intelligence Centrale, Confidentialité Totale."

## 🌟 Fonctionnalités Clés
-   **Smart Feed** : Un tableau de bord qui priorise proactivement votre journée.
-   **Drop Zone** : Glissez n'importe quel fichier (PDF, Note, Lien), l'IA le comprend et le classe.
-   **Mode Hybride** : Choisissez entre une IA 100% Locale (Privée) ou Cloud (Puissante & Censurée).

## 🛡️ Confidentialité & Sécurité
-   **Local First** : Par défaut, tout tourne sur votre machine via Ollama.
-   **Reversible Redaction** : En mode Cloud, les données sensibles sont anonymisées AVANT de quitter votre PC.

## Architecture
-   **Frontend** : Next.js (React)
-   **Backend** : Python (FastAPI)
-   **AI** : Ollama (Local) / OpenAI (Cloud Hybride)
